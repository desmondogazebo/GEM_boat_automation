# Granado Espada M Tools

This repository contains two independent Windows tools:

## DeathChecker

Monitors the game for death-screen details and sends authorized reports to the
DeathChecker service. Client setup, configuration, and troubleshooting are in
[DeathChecker/README.md](./DeathChecker/README.md).

## DailyShipHelper

Automates the ship trade-route workflow using Windows OCR and game-window input.
Build and usage instructions are in
[DailyShipHelper/README.md](./DailyShipHelper/README.md).

The two tools have separate launchers, settings, and runtime environments.
